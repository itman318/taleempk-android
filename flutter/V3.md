# TaleemPK Flutter v3.0

## Delivered in v3.0

- Native quiz runner with timer, answer submission, scoring and optional review.
- Persistent text-message outbox with stable client tokens and automatic retry.
- Native Privacy & Security center synced with the TaleemPK account.
- Signed-in mobile device list with per-device revocation.
- Native password change with optional sign-out of other mobile sessions.
- Existing premium chat, calls, media, reactions, polls, groups and notification badges retained.

## Reliability

- Queued text messages survive process restarts through SharedPreferences.
- Retried sends reuse the same client token to avoid duplicate messages on compatible servers.
- New outbox tests cover persistence, attempts, isolation and removal.
- Production CI builds directly from committed source after this migration is finalized.

## Known platform dependencies

- Guaranteed notifications while the app is fully killed still require server-backed FCM/OneSignal credentials.
- Existing web E2EE keys are not exported to the native client, so native UI does not claim full key-synced E2EE.
- Chat realtime transport remains optimized short polling until a WebSocket/SSE service is deployed on hosting.
